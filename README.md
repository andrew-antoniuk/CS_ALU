# 4-Bit ALU Logic Simulator

Програмний комплекс для моделювання та візуалізації роботи **4-бітного Арифметико-логічного пристрою (ALU)**. Цей проєкт дозволяє будувати та досліджувати цифрові схеми в реальному часі: від базових логічних гейтів до складних обчислювальних систем.

---

## Основні можливості

* **Інтерактивний GUI:** Зручний інтерфейс на базі PyQt5 для розміщення компонентів та малювання дротів.
* **Реальна симуляція:** Візуалізація стану дротів (зелений — логічна "1", червоний — логічний "0").
* **Ієрархічна логіка:** Побудова складних блоків на основі базових примітивів:
    * **Гейти:** AND, OR, NOT, XOR.
    * **Компоненти:** 1-bit Full Adder, 4-bit Ripple Carry Adder, 4-to-1 Multiplexer.
    * **ALU:** Повноцінний 4-бітний блок із підтримкою арифметичних та логічних операцій.

---

## Логіка роботи ALU

Ваше ALU підтримує 4 основні операції, які обираються за допомогою керуючих входів **OP1** та **OP0**:

| OP1 | OP0 | Операція | Опис |
|:---:|:---:|:---|:---|
| **0** | **0** | **ADD** | Додавання двох 4-бітних чисел ($A + B$) |
| **0** | **1** | **SUB** | Віднімання ($A - B$) через інверсію та додатковий код |
| **1** | **0** | **AND** | Побітове логічне "І" ($A \land B$) |
| **1** | **1** | **NOT** | Побітове логічне заперечення першого числа ($\neg A$) |

### Тестування в консолі

```python
from alu import demo_add, demo_sub, demo_and, demo_not, demo_counter

demo_add(5, 3)       # ADD: 5 + 3 = 8
demo_sub(7, 2)       # SUB: 7 - 2 = 5
demo_and(12, 10)     # AND: 12 & 10 = 8
demo_not(5)          # NOT: ~5 = 10 (4-bit)
demo_counter()       # COUNTER: 0 → 1 → 2 → ... → 7
```
